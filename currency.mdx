Monetary values in TruRisk — such as insured values, loss estimates, and recommendation loss estimates — are entered in the client's local currency. This is set on the client record when the client is created or edited, and is usually based on the client's locale (for example, US clients use USD).

You can view values in either of two ways:

- **The client's local currency** — values as they were entered for each client.
- **Your preferred currency** — all values converted into a single currency of your choice, so you can compare clients that use different currencies.

## Choosing how currency is displayed

Use the **currency button** in the top bar to switch between your preferred currency and each client's local currency, and to choose your preferred currency.

Your preference is saved to your user account, so it stays in place across sessions and devices. It only affects what you see — other users keep their own preferences.

## Exchange rates

Values are converted using exchange rates that are updated **once per day**. Conversion is for display only — the original values are never changed.
