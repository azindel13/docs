title: "Currency preference"
description: "Choose the currency TruRisk uses to display monetary values across the platform."
---

Monetary values in TruRisk — such as total insured values (TIVs), loss estimates, and costs to complete — are entered in the client's local currency. This is set on the client record when the client is created or edited, and is usually based on the client's locale (for example, US clients use USD).

You can view values in either of two ways:

- **The client's local currency** — values as they were entered for each client.
- **Your preferred currency** — all values converted into a single currency of your choice, so you can compare clients that use different currencies.

## Choosing a currency

Click the **currency button** in the top bar, then search for and select a currency, or select **Local currency** to show each client's values in their own currency. The setting applies across the whole platform: TIVs, loss estimates, costs to complete and other monetary values are all shown in the currency you choose, with the exceptions below. Hover over the currency button to see which currency values are shown in.

To see how a converted value was calculated, hover over it. A breakdown shows the original currency and value, the conversion rate used, and the converted value.

Your choice is saved to your user account, so it stays in place across sessions and devices. It only affects what you see — other users keep their own preferences.

## Values that stay in the survey currency

So that values are always entered consistently, some survey values aren't affected by the currency button:

- **Loss History** and **Major Updates** on the survey's [Survey Details](/survey-details) tab always show and take values in the survey's currency.
- **Loss Estimate** values are entered in the survey's currency when you create or edit the loss estimate. In view mode, they follow the currency button like other values. See [Insured values and loss estimates](/insured-values-and-loss-estimates).

## Exchange rates

Values are converted using exchange rates that are updated **once per day**. Conversion is for display only — the original values are never changed.
