The **Activities** tab on a client or site record shows all activities that have been scheduled for that client or site. You can track completion, filter by status, and open individual activity records.

## Summary cards

The top of the Activities tab displays four summary cards:

| Card | Description |
|------|-------------|
| **Total** | Total number of scheduled activities |
| **Done** | Completed activities, including those pending approval |
| **Missed** | Activities that were not completed before the late submission deadline |
| **Available** | Activities currently available to be completed, including overdue ones |

## Activity list

Below the summary cards, all activities are listed with the following columns:

| Column | Description |
|--------|-------------|
| **Activity Name** | The name of the activity template |
| **Sites** | The site(s) the activity is assigned to |
| **Program Repeat** | Whether the activity is a one-off or part of a recurring schedule |
| **Next Available** | The date the next instance of the activity becomes available (for repeating activities) |
| **Completion Rate** | The percentage of assigned users who have completed the activity |

Use the **Search Activities** bar, **Site** filter, and **Status** filter to narrow down the list. The **Completed** and **Available** date filters let you filter by the completion or availability date range.

## Activity statuses

| Status | Meaning |
|--------|---------|
| **Available** | Assigned and waiting to be started by the user |
| **Overdue** | Available but past the due date |
| **Done** | Completed by the assigned user |
| **Pending approval** | Completed and awaiting review by a risk engineer |
| **Missed** | Not completed before the late submission deadline |
